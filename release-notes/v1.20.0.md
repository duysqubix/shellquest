# v1.20.0 — Know What You're Wearing Before You Sell It

Your inventory has been growing for a while now. By prestige 2 you've got a Scythe of Segfault `[Enchanted +3]` rubbing shoulders with three Pikes of Ping in different rolls and a Ring of Fortune you can't remember the base power on. `sq inventory` shows you a list. `sq status` shows you the loadout. Neither one tells you what you actually have. `sq identify` does.

---

## 🔍 The Identify Command

Point at any equipped item or inventory item, get its full card back. Stats, modifiers, prices, source.

```
$ sq identify scythe
🔍 Item Details
──────────────────────────────────────────
  Name:        Scythe of Segfault
  Slot:        Weapon
  Rarity:      Rare
  Base power:  +12
  Enchant:     [Enchanted +3]
  Effective:   +15  (base 12 + enchant 3)
  Buy price:   169 gold
  Sell value:  84 gold base + 99 gold enchant bonus = 183 gold
  Source:      Equipped (Weapon slot)
──────────────────────────────────────────
```

Base power vs effective power, finally side by side. The sell value breaks out into the half-buy-price base and the enchant bonus so you can see at a glance how much of your sale value came from the gold you poured in.

For inventory items, the source line changes to your slot position:

```
$ sq identify pike.2
🔍 Item Details
──────────────────────────────────────────
  Name:        Pike of Ping
  Slot:        Weapon
  ...
  Source:      Inventory slot 4 of 11
──────────────────────────────────────────
```

For potions, the card swaps the power lines for a `Heals:` line — potions don't enchant, so no need to pretend:

```
$ sq identify common potion
🔍 Item Details
──────────────────────────────────────────
  Name:        Common Potion
  Slot:        Potion
  Rarity:      Common
  Heals:       5
  Buy price:   30 gold
  Sell value:  15 gold
  Source:      Inventory slot 7 of 20
──────────────────────────────────────────
```

## 🆔 The `id` Alias

Three keystrokes when you're in a hurry:

```
$ sq id ring of fortune
🔍 Item Details
...
```

Same matcher as `sq equip`, `sq drop`, `sq sell` — exact name beats substring beats fuzzy tokens, and `.1` / `.2` selectors disambiguate when you've hoarded duplicates.

---

## 🏠 Read-Only, Anywhere

Identify never writes the save file. No home-directory restriction. No tick consumed. Whether you're standing in `~`, mid-`cd` to a project, or deep inside `/var/log/something`, `sq identify` works the same.

It searches BOTH equipped slots AND your inventory in one pass. Equipped matches come first, so when the same name appears in both places the equipped copy is shown by default — append `.2` to flip to the inventory copy.

```
$ sq identify scythe       # → equipped Scythe
$ sq identify scythe.2     # → inventory Scythe
```
